MINIMARKET GO - AVANCE SEGUNDA EVALUACION

Proyecto coherente con el documento de avance corregido.
Contiene tres Activity: Inicio, Pedido y Resumen.
Incluye navegación, paso de información, cálculo de subtotal, IVA del 19%, delivery, total y validaciones básicas.
La boleta muestra únicamente los productos comprados, con cantidad, precio unitario y subtotal individual.

Para abrirlo: descomprimir el ZIP y seleccionar la carpeta MiniMarketGo_Corregido en Android Studio.
